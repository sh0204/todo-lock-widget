# ⚡️ 코딩 없이 쓰기 — 단축어 + 기본 위젯

앱을 빌드하지 않고도 **아이폰 기본 앱만으로** 비슷하게 쓸 수 있어요.

```
[잠금화면 버튼] → [단축어: 할 일 입력] → [미리 알림 저장 (날짜 포함)]
                                              ↓
              [캘린더 앱/위젯에 자동 표시] ← iOS 18+ 미리 알림이 캘린더에 함께 표시
```

## 1. 단축어 만들기

**단축어 앱 → + → 동작 추가**

1. **입력 요청**: 유형 `텍스트`, 질문 `할 일이 뭐예요?`
2. **입력 요청**: 유형 `날짜 및 시간`, 질문 `언제까지?`
3. **미리 알림 추가**
   - 제목 = 1번의 `제공된 입력`
   - `>` 펼치기 → **알림** 켜고 날짜 = 2번의 `제공된 입력`
4. *(선택)* **새로운 이벤트 추가**: 제목/시작 날짜를 똑같이 연결

이름: `할일추가`

## 2. 캘린더에 미리 알림 표시

**캘린더 앱 → 하단 "캘린더" → "미리 알림" 켜기**

## 3. 잠금화면 꾸미기

잠금화면 길게 누르기 → **사용자화 → 잠금 화면**

| 위치 | 넣을 것 |
|---|---|
| 시계 아래 위젯 칸 | **캘린더**(다음 일정) + **미리 알림**(오늘) |
| 하단 좌/우 버튼 | ➖로 하나 빼고 **➕ → 단축어 실행 → `할일추가`** |

## 팁

- 잠금 상태에서 실행하면 저장 전에 Face ID를 요구할 수 있어요.
- iPhone 15 Pro 이상: **설정 → 동작 버튼 → 단축어**에 같은 단축어를 넣으면 더 빨라요.
- 날짜를 매번 고르기 귀찮다면 2번을 지우고 알림 날짜를 `현재 날짜`로 두세요.
